# ספר הפעלה (Runbook): סיכום

המסמך המלא באנגלית: [runbook.md](runbook.md). לניפוי הודעה אחת: מסננים לפי `labels.correlationId` (מזהה ההודעה) או `labels.agentTurnId`; השאילתות ב-[observability.md](observability.md#how-to-debug-a-message). בכל התראה יש ערך אחד: מה היא אומרת, איך בודקים (נתיב ב-Cloud Console, פקודות gcloud ושאילתת לוגים לפי שדות הלוג המובנים), מה עושים, ומתי מסלימים או משהים פרסום.

- **התראות קיימות:** בדיקת תקינות ה-web נכשלת, תגובות 5xx ב-web, שורות שגיאה בלוגים, ועומס CPU או דיסק ב-Cloud SQL.
- **השהיית פרסום:** מהקונסולה הפנימית: השהיה גלובלית (`POST /console/api/system/pause`) או השהיה של עסק אחד. השהיה דוחה עבודה בלי לשנות מצב של פוסטים, והיא תמיד בטוחה והפיכה.
- **הסלמה:** לאדם כשיש חשש לפוסט שגוי, כפול או אבוד, לחשיפת מידע, או כשהתיקון דורש פריסה, Terraform, מיגרציה או שינוי סוד. סוכנים לא פורסים ולא מריצים apply.
- **נגישות לקונסולה:** דרך כניסת IAP (הפלט `console_url`): ‏load balancer ב-stage וב-prod, ו-IAP המובנה של Cloud Run ב-dev, עם חשבון Google שמופיע ב-`console_members`; כל פעולה נרשמת עם האימייל. ראו [security.md](security.md#console-exposure).
- **התראות WP-49:** שיעור כשלי פרסום, שגיאות webhook, צבירת תור משימות, worker לא רץ, ערוץ מנותק, קפיצת עלות מודל, קפיצה בכשלי תיקוף של מודל, חיבורים ל-SQL קרובים למקסימום, וצריכת תקציב שגיאות (SLO). לכל אחת ערך עם בדיקה, פעולה, והסלמה.
- **תקציב הסוכנת הכולל נגמר:** כל תור של סוכנת עובר לאדם עד חצות UTC. לטפל בשיחות מהקונסולה, לבדוק אם עסק או משימה בלולאה, ולהגדיל את התקרה רק באישור האדם.
