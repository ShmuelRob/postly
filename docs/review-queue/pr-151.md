# Infra aggregate check and a stricter docs-only lane

A follow-up to [pr-147.md](pr-147.md). What to check:

- **`infra-check`** (`.github/workflows/infra.yml`). It passes only when `changes` passed and the image and Terraform jobs passed or were skipped by the path filter. Once it is required on `dev`, a broken `infra.yml`, which produces no `infra-check`, blocks the merge.
- **The docs-only lane** (`scripts/lane.ts`) no longer counts `CLAUDE.md`, `PRD.md` or `docs/product-spec.he.md`, so those always run the full CI and get a normal review.
- **Merge rule.** Auto-merge is already on in the repository. Until `review` is a required check, `--auto` merges on `check` alone, so reviewers run it only after posting `review`.

## עברית

בדיקה מצרפית חדשה ל-Infra בשם `infra-check`, כדי שקובץ workflow שבור יחסום מיזוג במקום לעבור בשקט. במסלול "מסמכים בלבד" כבר לא נכללים CLAUDE.md, ה-PRD והמראה העברית שלו. auto-merge כבר פעיל, ולכן הסוקר מפעיל אותו רק אחרי שפרסם את `review`.
