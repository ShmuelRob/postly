# Dev sandbox open to anyone with the link (`sandbox_public`)

A security exposure the human asked for on 2026-11-09, dev only and reversible. What to check:

- **The switch** (`infra/modules/stack/main.tf`, `infra/environments/dev/`). `sandbox_public` defaults to `false`; Terraform refuses it outside dev or without the sandbox. When `true`, only `postly-dev-sandbox` changes: `iap_enabled` off and one `roles/run.invoker` grant to `allUsers` (the `cloud_run` module's `public` input). The console keeps IAP, and the bans on `allUsers` in `sandbox_invokers`, `sandbox_members` and `console_members` stay.
- **Reversible.** Every IAP grant, the OAuth client, `cloud_run_iap` and `SANDBOX_URL` stay as they are, so `sandbox_public = false` and an apply restore Google sign-in with no manual step.
- **Risk while on** ([security.md](../security.md#sandbox-exposure)). Anyone with the URL can chat with the dev agent as the owner, start sign-ups, and see the sandbox's dev test data; each message makes paid Vertex AI calls, bounded only by dev's monthly budget alert. Dev runs on simulators, so no real customer, channel or payment is reachable.
- **Decide** how long it stays on, and turn it off before any real business data reaches dev.

## עברית

מתג חדש `sandbox_public` (רק ב-dev, כבוי כברירת מחדל) פותח את ה-sandbox לכל מי שיש לו את הקישור, בלי כניסה עם Google, לבקשת האדם. כל הגדרות ה-IAP נשארות, והקונסולה נשארת מאחורי IAP, אז `sandbox_public = false` ו-apply מחזירים את הכניסה. הסיכון: כל אחד מדבר עם הסוכן של dev על קריאות Vertex בתשלום ורואה את נתוני הבדיקה; אין גישה ללקוחות או לערוצים אמיתיים.
