# One bad agent call no longer sinks the step; agent cost caps raised; drafts prompt v3

On dev (2026-11-09 21:56Z) a drafts turn handed the owner off: one `create_draft` in the step did not match its schema, so the whole step was an invalid model output, the log said only `calls.#`, and the retry did not fit the 0.02 USD step cap. What to review:

- **H1, a contract and runtime-rule change** ([agent.md, One bad call does not sink the step](../agent.md#one-bad-call-does-not-sink-the-step); `src/contracts/agent.ts`, `src/modules/agent/runtime.ts`). New `AgentStepOutput`: the model layer accepts a step whose calls name known tools, and the step is invalid only when no call matches its tool's schema. The runtime parses each call. A mismatch is refused as `invalid_input` and **does not stop the step**, unlike every other refusal, which does. All of a step's schema refusals count as one refusal toward `maxRefusals`. Check that letting the valid calls of a step run, when an earlier call in it was malformed, is acceptable. Such a call never reaches its tool, and calls that depend on it are refused by their own checks.
- **H4, migration `drizzle/0026_agent_step_caps.sql`**: `max_cost_usd` for the three agent tasks goes from 0.02 to 0.05 USD (attempts have cost 0.004 to 0.022 USD, so a retry always fits). `agent_config.max_turn_cost_usd` goes from 0.06 to 0.15 USD, which changes the A4 decision: without it, a 0.05 USD step cap would allow only one step per turn. Only rows still at the old values change. Worst case per turn is about 0.15 USD; the per-business 1.00 USD a day and the global 50 USD a day stay.
- **H7, `agent_drafts` prompt version 3** (in the same migration): version 2 plus one block of shape rules the Vertex response schema cannot hold: hashtags start with `#` and have no spaces; a caption for each network of the post, with only `instagram` or `facebook` as keys; the title at most 40 characters with at most one line break; a discount or price badge has exactly `kind`, `text` and `factId`, and a sticker has `kind` only; a crop stays inside the photo and rotation goes in 0.5 steps; ids are copied exactly; no extra fields. Check the Hebrew wording.
- **e2e**: a new test in `test/e2e/drafts-agent.e2e.test.ts`. The first output is invalid and retried; in the retry, one bad call is refused while the good one runs; the owner gets both drafts.
