# מודולים: סיכום

סיכום בעברית של [src/modules/README.md](../src/modules/README.md).

- לכל מודול מהתכנון הטכני יש תיקייה `src/modules/<name>/` עם `index.ts`, שהוא הממשק הציבורי היחיד שלו.
- מודול אחר, או קוד מחוץ ל־`src/modules/`, מייבא רק את `index.ts` של המודול, לא קבצים פנימיים.
- ספריות של ספקים חיצוניים (למשל Twilio) מיובאות רק בתיקיית `adapters/` של המודול שאחראי עליהן.
- דרייברים של מסד הנתונים והחיבור עצמו נשארים בתוך `src/db/`; שאר הקוד ניגש למסד דרך פונקציית הקשר העסק (`withBusiness()`) ב־`src/db/index.ts`.
- הכללים מוגדרים ב־`.dependency-cruiser.mjs`, רצים ב־`npm run check`, ו־CI חוסם מיזוג כשיש הפרה.
- מודול חדש, ספק חדש או כלל חדש: הוראות בקובץ האנגלי.
