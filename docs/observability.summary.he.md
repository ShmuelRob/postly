# תקציר: ניטור ולוגים

מסמך המקור: [observability.md](observability.md).

- **לוגר אחד** ב-`src/shared/logger.ts` לכל התהליכים (web, worker, console, migrate). אסור `console.*` במקום אחר ב-`src/`; בדיקה נכשלת אם יש.
- **פורמט:** שורת JSON אחת ב-stdout בפורמט ש-Google Cloud Logging קורא: `severity`, `message` קבוע באנגלית, `time`, שדה ה-trace, ו-labels עם המזהים.
- **מזהי קישור:** `AsyncLocalStorage` נושא את `requestId`, `businessId`, `messageId`, `jobId`, `jobName` ו-`process`. השרת פותח הקשר לכל בקשה, כל job רץ בהקשר משלו, וטיפול בהודעה נכנסת מוסיף את מזהי העסק וההודעה.
- **בלי תוכן לקוח, מספרי טלפון או סודות:** שדות בשמות כמו `text`, `phone`, `token`, `password` מוחלפים ב-`[redacted]`; בכל מחרוזת מוחלפים מספרי טלפון, סיסמאות ב-URL, טוקני Bearer ומחרוזות דמויות מפתח. מחרוזות נחתכות ב-500 תווים. בדיקה נכשלת אם תוכן או סוד מגיעים לשורת לוג.
- **שמירה:** 7 ימים ב-dev, 30 ב-stage וב-prod.
- מדדים ו-tracing (WP-48), לוחות והתראות (WP-49) ו-runbook (WP-50) יורחבו כאן.

## לוחות מחוונים והתראות (WP-49)

- המודול `infra/modules/monitoring` מגדיר לכל סביבה (dev, stage, prod) את אותם לוחות ואותן התראות. CI מריץ `terraform validate` בלבד; אף סוכן לא מריץ `apply`.
- **מקורות:** מדדי המוצר של WP-48 (`workload.googleapis.com/postly.*`, בלי מזהה עסק), מדדים מבוססי לוגים משורות WP-47 (לפי `message` ו-`labels.businessId`), ומדדי Cloud Run ו-Cloud SQL המובנים.
- **מדדים מבוססי לוגים:** שורות שגיאה, אירועים לפי עסק (business_id, event, severity), שגיאות webhook לפי נתיב, וניתוק ערוץ (השורה `channel disconnected`, שבדיקת התקינות היומית של מודול הפרסום כותבת כשערוץ מתנתק).
- **לוחות:** סקירת שירות (בקשות, השהיה, 5xx, מופעים, CPU, זיכרון, חיבורים ודיסק של Cloud SQL); זרימת מוצר (הודעות נכנסות ויוצאות, טיוטות, אישורים, פרסומים לפי תוצאה, עלות והשהיה של המודל לפי משימה, תורים); ולוח לכל עסק עם מסנן `business_id`.
- **התראות חדשות:** שיעור כישלונות פרסום, שגיאות webhook, תור תקוע, worker לא רץ, ניתוק ערוץ, קפיצה בעלות המודל, קפיצה בכישלונות אימות של המודל, חיבורי Cloud SQL קרובים ל-`max_connections`, ושריפת תקציב השגיאות. לכל התראה קישור לסעיף שלה ב-`runbook.md`.
- **תקציב שגיאות:** SLO של 99.5% בקשות web בלי 5xx על פני 28 יום; ההתראה יורה כשקצב השריפה מעל פי 10 במשך שעה.
