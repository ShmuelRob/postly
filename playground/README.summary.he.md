# מגרש משחקים מקומי (WP-45): תקציר

סביבה מקומית בלבד לניסוי Postly לפני חיבור אמיתי ל-WhatsApp, Instagram או Facebook. מסמך מלא באנגלית: [README.md](README.md).

- מפעילים עם `npm run playground` ופותחים את http://127.0.0.1:5175. נדרש Docker (או `TEST_DATABASE_URL`).
- **צ'אט** בסגנון WhatsApp, מימין לשמאל: אתם בעלי העסק. אפשר לשלוח טקסט, תמונות, הודעות קוליות (קובץ שמע) וללחוץ על כפתורים. ההודעות עוברות במודול ההודעות האמיתי ובסימולטור.
- **פיד** מדומה של Instagram ו-Facebook: מה שהגיע לסימולטור הפרסום, עם התמונות.
- **לוח מצב**: מצב העסק, שלב השיחה, הפוסטים ותור הבדיקה, מתוך מסד הנתונים.
- כרגע אין עדיין זרימת מוצר, ולכן התשובות הן "הד" עם טקסט זמני. כשתתווסף זרימת ההצטרפות (WP-30) היא תחובר ב-`server/flows.ts`.
- לא נפרס לעולם: התלויות הן לפיתוח בלבד, וכלל גבולות אוסר על קוד המוצר לייבא מהתיקייה.
